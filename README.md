## Como executar

1. Tenha o Python 3 instalado.
2. Abra esta pasta no VS Code ou em um terminal.
3. Execute `python main.py`.

## Funcionamento

- O programa contém 10 perguntas em um dicionário.
- Cada pergunta possui ID, enunciado, quatro alternativas e o número da resposta correta.
- O jogador informa seu nome ou apelido e escolhe responder 5 ou 10 perguntas.
- As perguntas são sorteadas sem repetição dentro da partida.
- É possível responder com `a`, `b`, `c`, `d` ou com o número de 1 a 4.
- Entradas inválidas são solicitadas novamente; pressionar Enter na escolha de quantidade seleciona 5 perguntas.
- A cada resposta, o jogador recebe feedback imediato e, se errar, vê a alternativa correta.
- Uma barra de progresso acompanha a partida.
- Ao final, o programa mostra acertos, erros, pontuação e percentual, com uma mensagem personalizada.
- O jogador pode iniciar outra partida sem fechar o programa.
- O jogo pode ser encerrado a qualquer momento com `Ctrl+C` ou pelo fim da entrada.

O projeto utiliza somente recursos nativos do Python, sem banco de dados ou bibliotecas externas.
